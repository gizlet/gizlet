# Design

`cartridge.html` is the chosen visual direction for the site and store (warm paper, signal orange, heavy grotesk, gizlets as cartridges). It is a static mockup with placeholder art. The home page (`src/home.ts`) and the shared header, footer and stylesheet (`public/static/site.css`) are built in it, with system fonts instead of Archivo and Space Mono, since the CSP allows no outside fonts; the share and account pages still use a plain layout.
